# CCOS Research Lab Agent Bootstrap Contract

Before autonomous coding, vendored-engine changes, generated-code isolation changes, Core/Enterprise promotion, ecosystem integration, PR creation, or merge decisions, read:

```bash
git fetch origin agent/ecosystem-roadmap && \
git show origin/agent/ecosystem-roadmap:.agent/CCOS_RESEARCH_LAB_ECOSYSTEM_ROADMAP.yaml
```

If the roadmap cannot be fetched or read, fail closed for major vendored-semantic, generated-code-isolation, product-promotion, cross-repository, or merge decisions. Read-only diagnosis is allowed.

This repository is experimental and outside the stable CCOS Core and governed CCOS Enterprise boundaries. Nothing here becomes a Core or Enterprise guarantee automatically.

Preserve exact lineage for embedded RSI, Forge, SLHAv2, OctaSoma and other engines. Before changing shared semantics, compare against the owning repository. Generated-code execution must use an isolation boundary that matches the claim; process limits alone are not automatically a sandbox.

Negative experiments remain evidence. Core promotion requires independent deterministic/replay/security qualification; Enterprise promotion additionally requires tenancy/authorization/governance qualification.

Required CI must be green on the exact PR head before merge.

Reread the roadmap at every session start, before embedded-engine/sandbox changes, before product promotion, before ecosystem integrations, and before relevant PR/merge decisions.

Do not merge the roadmap itself into `main` unless the user explicitly requests it.
