# DGM Sandbox

DGM and Forge generated-code evaluation use the shared `ccos-sandbox` runner. Bubblewrap is mandatory: if `/usr/bin/bwrap` (or `/bin/bwrap`) is absent, execution is refused and there is no direct-process fallback. The runner clears the environment, denies networking, uses a private PID namespace and `/tmp`, mounts system paths read-only, bounds captured output, and kills the complete process group on timeout. This is Linux-specific rootless isolation; resource limits and sandboxing are distinct controls and neither proves semantic safety. GPU, host home, SSH, Docker, and D-Bus sockets are not exposed in the untrusted profile.
