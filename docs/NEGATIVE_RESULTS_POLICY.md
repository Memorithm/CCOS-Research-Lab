# Negative Results Policy

**Negative results are preserved.** An experiment that refutes a hypothesis is
a result — hiding it is scientific misconduct on this project (§39, §51).

## Rules

1. Every registered experiment records its outcome including `refuted` and
   `not confirmed` classifications (EXPERIMENT_REGISTRY.md).
2. No experiment may be deleted from the registry; corrections append a new
   row referencing the old one.
3. A refutation of a Core hypothesis (H1–H7) is reported to the Core
   hypothesis file as evidence — marked `research-only` until replicated
   inside the Core boundary.
4. Reports must include the setup needed to reproduce the negative result
   (REPRODUCIBLE_EXPERIMENTS.md), not only the conclusion.
5. Publication of any CCOS benchmark result (positive or negative) requires
   the approval of ZEKRITI Tarek (§40).
